# Steelbind

A medieval fencing duel that runs in the browser.

**Play: https://financeflynn5-wq.github.io/steelbind/**

Your blade holds one of three lines: high, mid or low. A thrust that arrives on the line you hold is parried on its own, so thrust where their blade is not. A parry binds the blades and gives you the riposte. A hit knocks the plate off that line; a hit on a bare line is a touch. Three touches win.

| | |
|---|---|
| Step | `A` `D` |
| Line | mouse height, or `W` `S` |
| Thrust | left click |
| Beat | right click |
| Dash | `Space` |
| Pause | `Esc` |

Needs a keyboard and a mouse. Every model, texture, sound and note of music is generated in code; this repository holds the built game.
